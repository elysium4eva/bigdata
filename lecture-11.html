本讲不用 API Key、不联网：共享模块里的 LocalChatModel 模仿 OpenAI 的消息结构 （messages、temperature、max_tokens），内部是 n-gram 语言模型， 所以每一个例子都可离线复现，而且概率是可看的。把 model= 换成真模型即可接真实 API。

一条主线：词 → 概率 → 对齐 → 提示 → 工具 → 检索 → 应用 → 风险。 从词到概率（分词、embedding、注意力、缩放定律、上下文窗口、温度与采样、幻觉的结构性原因）→ 训练与对齐（SFT、RLHF、DPO、RLVR、推理模型与测试时计算、蒸馏、对齐税、评测与数据污染）→ 提示工程（五要素、结构化输出与 schema 校验、少样本、CoT、自洽投票、反思、长文档、提示注入与防御）→ 工具·Agent·RAG（函数调用、四件套、MCP、六步流水线、切分、混合检索、评测）→ 六个应用场景（内容创作、写作办公、学术写作与引用校验、编程、电商文案、跨境电商）→ 风险与 2026（三类幻觉、三层护栏、伦理与内容标识）。

Part 3提示工程：五要素、结构化输出与 schema 校验、少样本、CoT、自洽投票、反思、长文档三策略、提示注入与防御、四个反模式

Part 7工具、术语与结语：工具栈、术语表两帧（81 条）、参考资料、一页纸回顾、结语

一、它为什么能写 Principles
大语言模型large language model (LLM)用海量文本训练的下一个词预测器
tokentoken模型处理的最小单位
分词tokenisation把文本切成 token 的过程
BPEbyte-pair encoding常用子词切分算法
词向量embedding$e(w)\in\mathbb{R}^d$把词映射成向量
Transformertransformer靠注意力堆叠的序列模型
注意力attention$\mathrm{softmax}(QK^\top/\sqrt{d})V$按相关性加权取信息
logitslogitssoftmax 之前的原始分数
softmaxsoftmax$p_i=e^{z_i}/\sum_j e^{z_j}$把分数变成概率
温度temperature$T$ $z_i/T$越高越随机
top-p 采样nucleus sampling只在累积概率 p 内采样
上下文窗口context window模型一次能看到的 token 数
预训练pretraining在海量文本上学下一个词
缩放定律scaling law$L\propto N^{-\alpha}$loss 随规模幂律下降

零样本zero-shot不给例子直接做
少样本few-shot给几个例子再做
提示工程prompt engineering把任务写清楚并给出格式
系统提示system prompt设定角色与规则的前置指令
结构化输出structured output要求 JSON/表格等固定格式
思维链chain-of-thought (CoT)先写步骤再给结论
自洽投票self-consistency多次采样取多数
反思reflexion让模型检查并修改自己的输出
提示注入prompt injection文档里的指令劫持模型
角色扮演role prompting让模型扮演某个身份作答
三、训练与对齐 Alignment
监督微调supervised fine-tuning (SFT)用示范答案教它照做
人类反馈强化学习RLHF奖励模型 + 策略优化
奖励模型reward model学人类偏好打分的模型
PPOproximal policy optimisation常用的策略优化算法
直接偏好优化DPO跳过奖励模型直接优化偏好
可验证奖励RLVR用答案对错当奖励
推理模型reasoning model先想再答的模型
测试时计算test-time compute推理时多花算力
蒸馏distillation用大模型教小模型
对齐税alignment tax对齐带来的能力损失
数据污染data contamination测试集混进了训练集

函数调用function calling模型输出要调用什么工具
工具调用tool use让模型使用外部能力
智能体agent模型 + 工具 + 循环
规划planning把任务拆成步骤
记忆memory跨轮次保存的上下文
MCPmodel context protocol工具接入的标准协议
检索增强生成retrieval-augmented generation (RAG)先检索再生成

向量数据库vector database存向量并做相似检索
重排reranking对召回结果再排序

BM25BM25经典关键词打分

拒答率refusal rate不知道时说不知道的比率

内容标识content provenance标注 AI 生成内容

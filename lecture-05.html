Lecture 5　Introduction to Machine Learning

本讲是机器学习总览课：四类学习范式（监督 / 无监督 / 自监督 / 强化）、 训练-验证-测试与交叉验证、偏差-方差与三类误差、回归与分类指标（含阈值、代价敏感与概率校准）、 监督算法族（线性与惩罚回归、KNN、SVM、CART、随机森林、梯度提升 XGBoost / LightGBM）、 无监督算法族（PCA 与因子、k-means、层次聚类、DBSCAN、GMM/EM、异常检测与关联规则）、 神经网络与强化学习（前向传播、激活函数、反向传播、Q-learning）， 以及 2026 内容（AutoML 取舍、可解释性 SHAP/PDP/ICE、模型卡与 MLOps、数据泄漏清单、公平性与合规、成本与延迟）。 全部示例用 Python 完成，每一行代码都带英文注释，一条 run_all.py 即可重建样本、图表与实验记录。

本讲结构 Outline

Part 0封面与导航：学习目标、路线图、与 L4 衔接、本讲输出物（基线模型与评估协议 + 数据泄漏清单 + 模型卡与运行记录）、全讲导览
Part 1概念与版图：三个问题切入、Mitchell (1997) 的 E/T/P 定义、AI·ML·DL·生成式 AI 版图、金融七类应用与投研文档分析、"找模式用模式"、监督 / 无监督 / 深度与强化总述、监督与无监督对照表
Part 2流程、划分与评估协议：预测问题与因果问题、两种自省（说的与做的）、ML 与计量经济学三处差别、P≫N 会发生什么、计量经济学的关键教训、ML 1-2-3、训练/验证/测试、五种划分器与交叉验证、端到端流水线与基线样本页、划分与交叉验证代码页、四种协议与数据泄漏样本页
Part 3泛化、偏差-方差与评估：过拟合与欠拟合、三种复杂度样本页、复杂度扫描代码页、偏差²+方差+噪声分解、学习曲线诊断与两种含义、防过拟合两原则与奥卡姆剃刀、正则化路径样本页、泛化误差与归纳偏置、回归指标、分类指标、指标/阈值/校准样本页、代价敏感与阈值、指标与校准代码页、概率校准与不确定性
Part 4监督学习算法族：算法族地图、线性与多元回归、Ridge/Lasso/Elastic Net、回归族对照与正则化路径（样本 + 代码）、KNN、SVM、KNN/SVM 边界样本页、CART 与集成、梯度提升族（XGBoost / LightGBM / CatBoost 实测计时）、树与集成样本页与代码页、朴素贝叶斯与 LDA、相似度学习与向量检索、选型决策表、scikit-learn 估计器地图
Part 5无监督学习算法族：用途与评估困境、PCA（碎石图/载荷/重构）、PCA 与因子样本页与代码页、因子分析与 Fama-French、非线性降维与嵌入、聚类四族总览、k-means 与常见误用、层次聚类/DBSCAN/GMM 与 EM、聚类三法样本页与 k 选择代码页、聚类评估/异常检测/关联规则
Part 6神经网络与强化学习：为什么需要神经网络、从多元回归到单隐层网络、单节点机制与激活函数、结构即超参数、MLP 训练样本页、前向传播、纯 NumPy 前向与反向传播代码页、训练循环与优化器、深度学习网、强化学习设定、Q-learning 网格世界样本页与代码页、自监督/迁移/微调、2026 取舍（自建 / AutoML / 微调 / 提示+检索）
Part 7可信、可解释与工程化：可解释性三类方法、解释性可视化样本页与模型卡代码页、数据泄漏清单、公平性与偏差指标、模型卡六要素、MLOps 四件事（版本/跟踪/监控/回滚）、AutoML 的成本与风险、成本与延迟预算、指标被优化之后的评测危机、高风险场景合规与教育红线、交付前自查清单
Part 8工具、项目与结语：工具栈（scikit-learn / XGBoost / LightGBM / Optuna / MLflow）、第 6 周项目选题说明模板（问题/数据/方法/产出）、常见错误 Top 10、术语对照与参考书（Géron Ch.1–3、ESL、Mitchell、Athey）、三句话讲清你的模型

代码示例（10 页，逐行英文注释）Code Walkthroughs

  • 端到端流水线与基线：划分、预处理、多数类基线与逻辑回归、运行记录 JSON（l5_01）；
  • 划分与交叉验证：分层 K 折、交叉验证分数、四种泄漏协议对照（l5_02）；
  • 复杂度扫描与学习曲线：多项式次数、Ridge 惩罚、learning_curve 诊断（l5_03）；
  • 指标、阈值与校准：ROC/PR 曲线、阈值—代价曲线、等渗校准（l5_04）；
  • 正则化回归：OLS/RidgeCV/LassoCV/ElasticNetCV 与系数路径（l5_05）；
  • KNN、SVM 与调参：k 与核参数、GridSearchCV、交叉验证对照（l5_06）；
  • 树与集成：单树深度扫描、随机森林、梯度提升、XGBoost/LightGBM 计时与置换重要性（l5_07）；
  • PCA 与重构误差：碎石图、载荷、投影与重构曲线（l5_08）；
  • 聚类与 k 选择：inertia/silhouette/Calinski-Harabasz、k-means/层次/DBSCAN 与 ARI（l5_09）；
  • 神经网络与强化学习：纯 NumPy 前向/反向传播（l5_10）、Q-learning 网格世界（l5_11）、解释性与模型卡（l5_12）。

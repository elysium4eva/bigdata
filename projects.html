二、交付物与提交方式

交付物形式与要求提交方式

项目过程源代码、AI Prompt 记录、Markdown 文档发老师电子邮箱，或线上提交（推荐使用 GitHub）

说明：纸质报告为必交项；电子材料用于证明过程的可复现性与真实性，建议在 GitHub 上以仓库形式组织 （含 README、代码、数据说明、Prompt 记录、展示链接），便于评审与复现。

三、项目总体要求

  1. 问题导向：运用大数据智能手段解决企业、产品出海中的实际问题。
  2. AI 使用边界：允许使用 AI 辅助，但禁止使用 AI 完成概念构想、流程设计等创造性过程； AI 的使用须留痕（Prompt 记录为交付内容之一），并在报告中说明使用范围。
  3. 报告格式：纸质 PDF 报告格式仿照营销方案、项目报告的格式撰写（含背景、目标、方法、结论与建议等要件）。
  4. 引用与合规：合规引用文献及其知识产权，明确文献及数据来源（数据许可、获取方式、时间范围）。

四、四个项目 Project Options

项目一：全球性事件影响下的出海潜在爆款产品市场需求分析

在全球性事件（例如厄尔尼诺现象、中东原油危机、中美贸易战等）的影响下，通过动态预测， 为中国企业在一个选定的全球市场中找出具有爆款潜力的出海产品，并完成市场需求分析。

  • 选题限定：产品尚未被市场证实；已被市场证实的产品不可选作研究对象。
  • 示例说明：欧洲极端高温下便于安装的空调、比亚迪海獭电动车等仅作为方向示例，可以借鉴其分析角度， 但不得直接研究已被市场验证的产品。

交付内容：

  1. 目标市场（国家 / 区域）的确定依据。
  2. 宏观市场分析。
  3. 微观潜在消费者的销量需求。
  4. 潜在的竞品分析。
  5. 对厂商与供应商的产品设计建议：如何通过更新产品设计提高销量。
  6. 测试并优化产品的预期市场结果。

项目二：跨境电商平台数据挖掘与出口快消品营销方案

使用跨境电商平台数据挖掘识别跨境出口的快消产品，并为其建立营销方案。

交付内容：

  1. 挖掘商品的程序算法。
  2. 尽调当前该商品的主流营销方案与具体手段（如网络直播、内容营销等）。
  3. 提出新的营销策略，并使用人工智能赋能以提高该营销策略的效果。
  4. 验证你的策略是否更有效。

项目三：地缘政治冲突下的中国上市企业风险暴露因子与交易策略

利用国际地缘政治冲突构建中国上市企业的风险暴露因子，基于该因子设计交易策略，并对策略进行回测与优化。

交付内容：

  1. 因子构建的方法。
  2. 数据起始时间：2017 年贸易战开始之后。
  3. 提供具体基于价值投资的交易策略。
  4. 提供回撤结果，并与同类策略对比。

项目四：全球企业出海法律合规风险自动更新平台

生成一个可自动更新全球企业出海法律合规风险的网站或微信小程序，为企业提供出海法律合规风险评估分析。

风险评估维度（首先确定你评估的风险维度，可包括但不限于）：

风险维度含义说明
贸易合规风险关税、进出口管制、原产地规则、反倾销与反补贴等
地缘政治合规风险制裁与出口管制清单、投资审查、外交与区域冲突影响等
物流航运合规风险运输与保险、港口与航线限制、危险品与清关要求等
合同法务风险合同适用法律与争议解决、代理与经销协议、知识产权约定等
资本流动及结算法律风险外汇管制、跨境支付与结算、税务与转移定价等

交付标准与目标：客户能够通过输入企业名称、经营内容和范围，获取该业务在各个风险维度上的法律风险， 并可对各个国家、各个维度的风险设置风险系数。

交付内容：

  1. 可自动更新中国企业全球营商风险的数据库。
  2. 各个风险维度的可视化地图。
  3. 用户交互界面：通过输入公司和业务信息输出各个风险维度的风险系数。
  4. 使用大数据量化工具把文本信息转化为风险系数的数值。
  5. 根据风险评估，给出该公司全球（或指定市场）法律风险与法务咨询的报告。

五、项目评分规则（参考评分表，满分 100 分）

评分维度权重评分要点
问题与选题价值10出海实际问题是否明确、真实、可检验；选题是否符合项目边界（如项目一的产品未被市场证实）
数据获取与合规15数据来源是否明确标注许可与获取方式；数据质量、时间范围与规模是否支撑结论
方法与技术实现25是否使用恰当的大数据智能方法与量化工具；流程是否清晰；代码能否复现
结果与验证20交付内容是否完整（需求分析 / 营销策略验证 / 回测与对比 / 风险系数）；结论是否有验证
报告质量15格式是否仿照营销方案或项目报告；结构、图表、图注与参考文献是否规范；10 页以内
交付完整性与过程留痕10源代码、AI Prompt 记录、Markdown 文档与展示成果是否齐备
AI 使用合规与学术诚信5AI 使用是否留痕并说明范围；是否避免用 AI 替代创造性工作

评分说明：

  • 各维度按 5 档打分（优秀 / 良好 / 合格 / 待改进 / 不合格），加权汇总为百分制。
  • 否决项：创造性过程（概念构想、流程设计等）必须由团队完成；若发现由 AI 代做或存在抄袭、数据来源造假， 按学术不端处理，该项目可判为不及格。
  • 扣分项：交付物不完整（缺少纸质报告、源代码、Prompt 记录或展示成果）按缺失项扣分， 最高不超过该维度的 50%。
  • 加分说明：成果可复现、可在真实场景中使用、或对所选企业具有实际参考价值的，可在对应维度内取上限。

各项目关键交付物对照表（自查用）：

项目核心交付物建议体现的验证
项目一目标市场、宏观分析、微观需求、竞品、产品设计建议、预期市场结果动态预测过程与情景对比
项目二挖掘算法、主流营销方案尽调、新策略与 AI 赋能、有效性验证策略 A/B 或前后对照数据
项目三因子构建方法、2017 年后数据、价值投资策略、回撤与同类对比回测指标与稳健性检验
项目四自动更新数据库、风险维度地图、交互界面、文本→风险系数、风险评估报告风险系数口径与样例企业输出

六、其他说明

  • 以上 4 个项目的内容仅为框架，可对背景进行充实丰富，提高题目的实操性与专业性；具体题目在框架内细化， 并在学期末随选题信息一并提交。
  • 报告中需明确文献及数据来源；使用第三方数据、图表或代码时须遵守其许可与知识产权要求。
  • 建议尽早确认数据可得性（许可、时间范围、字段），以便在学期内完成完整的分析闭环。

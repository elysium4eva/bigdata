本讲新增 10 页样本数据与可视化：为数值型、类别型、结构化程度、文本、图像、音频、视频、图 / 网络、时空轨迹与三类数据结构各配一份样本数据、 一张可视化图与一个逐行中文注释的 Python 程序，全部随课程仓库发布，可一键重跑（详见 样本数据与可视化程序）。

本讲结构 Outline

Part 0封面与导航：学习目标、路线图、与 L1 衔接、本讲输出物（数据源清单 + 获取脚本 + 合规检查表）
Part 1数据类型、结构与测量：测量层级、数值/类别/复合类型、10 页样本数据与可视化（数值型、类别型、结构化程度、文本、图像、音频、视频、图 / 网络、时空轨迹、截面-时序-面板）、截面/时序/面板、截面关联与空间、结构化与非结构化、宽表与长表、聚合与粒度陷阱、抽样与总体、误差地图（覆盖→抽样→无响应→测量）、拿到数据先问的 10 个问题
Part 2已有数据来源（国际 + 中国）：来源全景与五维评估、内部数据、开放数据（World Bank/IMF/OECD/Comtrade/Eurostat/FRED；国家统计局/央行/海关/交易所/巨潮/企业信用公示）、第三方 DaaS（Bloomberg/Refinitiv；Wind/iFinD/CSMAR/CNRDS/CEIC）、CSMAR vs Wind、数据集平台（Kaggle/HF/UCI；天池/和鲸）、平台 API 生态与 REST 基础
Part 3非结构化与实时：PDF/OCR 与表格抽取、表格规范化与多源合并、LLM 结构化抽取、流式与实时（Kafka/Flink/CDC）、替代数据与合规评估、来源选择决策树
Part 4一手数据采集：问卷设计与偏差、抽样方法、实施方式与成本覆盖、无响应与加权、普查与行政数据、实验设计与 A/B 测试（流程与陷阱）、实验室实验、访谈、卡片分类
Part 5质量控制与 LLM 辅助：标注一致性（κ/α）、LLM 辅助采集与核验流程、合成数据与隐私增强（差分隐私/联邦学习）、数据体检报告
Part 6管道·治理·合规：ETL vs ELT、最小可用数据管道、数据契约与数据产品、现代数据栈与开放表格式、元数据与血缘、版本与可复现、数据质量规则、GDPR/CCPA/PIPL、版权许可与安全伦理
Part 7工作流、作业与结语：研究问题→数据需求、数据源清单模板与失败排查、作业 1 要求与评分、常见错误、参考书、数据源速查表（国际/中国）、术语对照

代码示例（9 页）Code Walkthroughs

  • REST API 通用骨架：会话、指数退避重试、分页、磁盘缓存、超时与日志；
  • World Bank API：按国家与指标批量拉取 → DataFrame → Parquet 落盘；
  • 金融数据：yfinance 多市场行情（含 A 股/港股代码）与 FRED 宏观序列；
  • 中国数据源：Tushare Pro（token/积分）与 AKShare（免费）示例；
  • PDF 抽取：pdfplumber 文本/表格 + 扫描件 OCR；
  • 表格规范化：编码、千分位、百分比、类别映射与多源合并去重；
  • LLM 结构化抽取：JSON schema 校验 + 抽样人工复核；
  • 数据体检：缺失、重复、异常（IQR）、时间覆盖；
  • 最小可用管道：快照 → 断言校验 → 幂等落盘 → 日志。

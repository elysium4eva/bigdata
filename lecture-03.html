本讲结构 Outline

Part 0封面与导航：学习目标、路线图、与 L2 衔接、输出物（数据集 + 脚本 + 质量报告 + AI 声明）、全讲导览
Part 1数据质量与整备总览：五项质量特征（有效性/准确性/完整性/一致性/单位一致，并说明大纲口径"唯一性"）、特征→检测→处置矩阵、粒度 grain、数据分层与数据契约、清洗 vs 转换 vs 重塑、清洗五步法总览、可复现五原则
Part 2合并与重塑：append/concat（加观测）、merge/join（加变量）、joinby 组内全组合、四种连接语义 + union、连接基数与行数爆炸、validate 与 indicator 对账、键标准化与实体对齐、宽表↔长表、pivot/pivot_table/crosstab、重塑工具箱与陷阱
Part 3数据清洗：清洗定义与收益、五步法逐步展开（去重与不相关观测、结构性错误、异常值弃留判断、缺失处理、验证与 QA）、异常值三法（IQR / Z-score / 稳健 Z / 隔离森林）、文本脏数据、近重复与模糊匹配、清洗审计与边界
Part 4缺失数据：非响应与流失、MCAR / MAR / MNAR 三种机制与模拟偏差、三种处理策略（插补/剔除/免插补分析）、插补方法族与 EM/MI、五种插补方法评分、插补的代价、缺失即信息、时间序列插值与外推、决策树小结
Part 5面板与平衡性：平衡 vs 非平衡面板定义、T=11/n=2 案例、名义平衡与内含缺失（T1=9, T2=11, T3=8）、非平衡的机制与样本选择、Stata xtset 与 pandas 覆盖体检、drop/gen/ipolate 对照、面板体检与插值补齐、中国地级市人口案例
Part 6变换、工具与工程化：对数/标准化/归一化/分箱、单位与量纲统一（Uniformity）、变换 + 断言管道、Stata→pandas 命令全表、pandas 速查、Polars 与 DuckDB、pandera / Great Expectations、dbt 与特征存储、LLM 辅助清洗、脱敏与隐私增强、漂移监控与回滚
Part 7项目与结语：项目 1「数据获取与整备」要求与评分、一页选题说明模板（第 6 周）、数据质量报告模板、30 项清洗清单、工具速查、术语对照、参考书、复现演练

代码示例（10 页，逐行英文注释）Code Walkthroughs

  • 质量画像与断言：把五项质量特征翻译为可计算指标，并写成断言；
  • append / concat 与 schema 对齐：列改名、类型统一、来源标记、行数守恒；
  • 安全合并：merge(validate=...) 让基数违规直接报错，indicator 对账；
  • 重塑工具箱：pivot / melt / stack / explode / get_dummies / cut / factorize；
  • 清洗五步法：去重、结构纠错、异常分类、缺失填充（带指示列）、断言与审计日志；
  • 异常值三法：IQR、Z-score、稳健 Z（MAD）、隔离森林，以及删除/缩尾/保留三种处置；
  • 缺失机制模拟：MCAR / MAR / MNAR 三种缺失的构造与朴素估计偏差；
  • 插补方法对比：均值、中位数、回归、KNN、MICE 的分布/相关系数/下游系数评估；
  • 面板体检与插值：覆盖率表、T_i、按个体插值并标注被插补的格子；
  • 变换 + 断言管道：log1p / 标准化 / 分箱 + 12 条 schema 断言（最小可用数据契约）。

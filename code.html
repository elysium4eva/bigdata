Lecture 2 · 数据类型样本（10 个程序，逐行中文注释）

课件页数据类型程序（逐行中文注释）样本数据
第 10 帧 数值型数据（连续 / 离散）
800 个交易日的日对数收益率与成交量的直方图、箱线图（离群点），以及每日订单数的离散计数分布。		 01_datatype_numeric.py numeric_samples.csv
第 12 帧 类别型数据（名义 / 有序）
行业（名义，6 类）与信用评级（有序，AAA–C）的频数条形图，以及行业 × 评级交叉热力图。		 02_datatype_categorical.py categorical_samples.csv
第 13 帧 结构化 / 半结构化 / 非结构化
定长字段表格、嵌套且字段可缺省的 JSON、无字段的自然语言文本三种形态并排对照。		 10_datatype_structured_unstructured.py structured_orders.csv、semistructured_orders.json、unstructured_note.txt
第 15 帧 文本数据
20 条财经短讯切词后的 Top-15 词频、逐篇字符数与长度分布（决定截断与填充策略）。		 03_datatype_text.py text_samples.csv
第 16 帧 图像数据
3 类 × 4 张 32×32 灰度样本马赛克、彩色图像三通道分解与像素强度分布。		 04_datatype_image.py image_samples.npy、image_labels.npy
第 17 帧 音频数据
8 kHz、1 秒的纯音 / 扫频 / 调幅噪声：时域波形、短时傅里叶频谱图与包络。		 05_datatype_audio.py audio_tone_440.wav、audio_chirp_200_2000.wav、audio_am_noise.wav
第 18 帧 视频数据
12 帧 48×48 序列（抽帧 PNG 在 data/video_frames/）、帧间差分运动检测与逐帧亮度信号。		 06_datatype_video.py video_frames.npy
第 19 帧 图 / 网络数据
60 节点 BA 无标度网络的力导向布局（节点大小与颜色表示度数）与度分布双对数图。		 07_datatype_graph.py graph_edges.csv、graph_nodes.csv
第 20 帧 时空轨迹数据
深圳南山周边 3 条轨迹 × 120 个点：经纬度路径、hexbin 空间密度与速度时间序列。		 08_datatype_spatiotemporal.py spatiotemporal_tracks.csv
第 23 帧 截面 / 时序 / 面板
截面排序条形图、含 12 期移动平均的 120 个月 CPI、8 家公司 × 10 年的面板小多图。		 09_datastructure_cross_time_panel.py structure_cross_section.csv、structure_time_series.csv、structure_panel.csv

运行方式：pip install -r code/requirements.txt → cd code && python run_all.py； 样本写入 data/，图片写入 figures/。随机种子固定 20260917，每次运行结果完全一致。

Lecture 3 · 数据整备样本（10 个程序，逐行中文注释）

运行方式：pip install -r code/lecture03/requirements.txt → cd code/lecture03 && python run_all.py； 样本写入 data/lecture03/，图片写入 figures/lecture03/。随机种子固定 20260317，每次运行结果完全一致。

课件页整备主题程序（逐行中文注释）样本数据
第 15 帧 质量画像仪表盘 Quality profile
600 行脏订单：18 个重复主键、城市 7 种写法、支付状态 6 种写法、70 行缺数量，一次量化五项质量特征。		 l3_01_quality_profile.py l3_orders_dirty.csv、l3_quality_scorecard.csv
第 22 帧 连接语义对照 Join types
inner 5 · left 6 · right 8 · outer 9 · union 10 行：五种操作的结果表与行数变化；含 validate 报错演示。		 l3_03_join_types_validate.py l3_customers.csv、l3_orders.csv、l3_dataset1.csv、l3_dataset2.csv、l3_dataset3.csv、l3_dataset4.csv
第 26 帧 concat 与 schema 对齐
两期订单抽取：朴素拼接 9 列（全空洞）→ 对齐后 7 列干净；行数与主键两条断言。		 l3_02_join_concat.py l3_orders_2026Q1.csv、l3_orders_2026Q2.csv、l3_orders_combined.csv、l3_concat_accounting.csv
第 29 帧 透视、交叉表与分箱
crosstab 频数、pivot_table 聚合、cut 等宽分箱与 qcut 等频分箱（6/6/6/6）。		 l3_04_reshape_toolbox.py l3_sales_wide.csv、l3_sales_long.csv、l3_sales_pivot.csv、l3_sales_long_enriched.csv
第 30 帧 宽表 / 长表 / 透视对照
4 门店 × 6 个月的三种摆法，含宽→长→宽往返无损断言。		 l3_04_reshape_toolbox.py l3_sales_wide.csv
第 38 帧 异常值三法
IQR 22 行 / Z 10 行 / 稳健 Z 17 行 / 隔离森林 13 行；四法一致仅 10 行；三种处置对比。		 l3_06_outliers_iqr_z_iforest.py l3_income_outliers.csv、l3_outlier_treatment.csv
第 41 帧 清洗前后对照
600 → 582 行；缺失 70 → 0（中位数填充 + 缺失指示列）；异常值标记而非静默删除。		 l3_05_cleaning_pipeline.py l3_orders_clean.csv、l3_cleaning_log.csv
第 46 帧 结构错误与类别规范化
城市 7 种写法 → 2 个城市；别名映射表本身也是交付物。		 l3_05_cleaning_pipeline.py l3_city_names_raw.csv、l3_city_names_map.csv
第 52 帧 缺失矩阵与机制偏差
MCAR / MAR / MNAR 三种机制的缺失矩阵与朴素均值偏差 −0.9% / −14.4% / −5.6%。		 l3_07_missing_mechanisms.py l3_missing_bias.csv、l3_income_missing_MCAR.csv、l3_income_missing_MAR.csv、l3_income_missing_MNAR.csv、l3_missing_panel_sample.csv、l3_missing_panel_coverage.csv
第 57 帧 插补前后：分布与关系
均值插补把分布压成尖峰；回归 / KNN / MICE 更接近真分布；方差收缩清晰可见。		 l3_08_imputation_compare.py l3_income_complete.csv、l3_income_missing.csv、l3_imputation_metrics.csv、l3_imputation_means.csv
第 62 帧 平衡面板 T=11, n=2
两家公司 11 个月的营收路径与个体 × 时间热力图（每格都有观测）。		 l3_09_panel_balance.py l3_panel_balanced.csv
第 68 帧 面板补齐前后热力图
T1=9 / T2=11 / T3=8 与块状缺失 → 按个体插值（2 格）并标注；5 格因期间不存在而无法补齐。		 l3_09_panel_balance.py l3_panel_unbalanced.csv、l3_panel_repaired.csv
第 72 帧 变换与标准化效果
偏度 ≈ 2.7 的营收经 log1p 后接近对称；12 条 schema 断言全部通过。		 l3_10_transform_assert.py l3_income_skewed.csv、l3_transform_summary.csv、l3_schema_report.csv

如何运行 How to Run

# 1) 安装依赖（Python 3.8+；本课程用 3.9 实测）
pip install -r code/requirements.txt
pip install -r code/lecture03/requirements.txt

# 2) Lecture 2：数据类型样本（逐行中文注释）
cd code
python run_all.py

# 3) Lecture 3：数据整备样本（逐行中文注释）
cd lecture03
python run_all.py

两个讲次的随机种子都固定（L2 为 20260917、L3 为 20260317）， 因此每次运行得到完全相同的样本与图片。

说明 Notes

  • 逐行注释：Lecture 2 与 Lecture 3 的程序、以及课件中的代码示例，每一行代码都带中文注释；
  • 数据来源：全部样本由程序合成（模拟订单、客户、收入、城市面板、语料、网络等），不包含任何真实个人数据，可自由用于教学与项目 1；
  • 与课件对应：L2 图片对应第 10、12、13、15–20、23 帧；L3 图片对应第 15、22、29、30、38、41、46、52、57、62、68、72 帧；

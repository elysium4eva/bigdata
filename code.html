Lecture 2 · 数据类型样本（10 个程序，逐行中文注释）

课件页数据类型程序（逐行中文注释）样本数据
第 10 帧 数值型数据（连续 / 离散）
800 个交易日的日对数收益率与成交量的直方图、箱线图（离群点），以及每日订单数的离散计数分布。		 01_datatype_numeric.py numeric_samples.csv
第 12 帧 类别型数据（名义 / 有序）
行业（名义，6 类）与信用评级（有序，AAA–C）的频数条形图，以及行业 × 评级交叉热力图。		 02_datatype_categorical.py categorical_samples.csv
第 13 帧 结构化 / 半结构化 / 非结构化
定长字段表格、嵌套且字段可缺省的 JSON、无字段的自然语言文本三种形态并排对照。		 10_datatype_structured_unstructured.py structured_orders.csv、semistructured_orders.json、unstructured_note.txt
第 15 帧 文本数据
20 条财经短讯切词后的 Top-15 词频、逐篇字符数与长度分布（决定截断与填充策略）。		 03_datatype_text.py text_samples.csv
第 16 帧 图像数据
3 类 × 4 张 32×32 灰度样本马赛克、彩色图像三通道分解与像素强度分布。		 04_datatype_image.py image_samples.npy、image_labels.npy
第 17 帧 音频数据
8 kHz、1 秒的纯音 / 扫频 / 调幅噪声：时域波形、短时傅里叶频谱图与包络。		 05_datatype_audio.py audio_tone_440.wav、audio_chirp_200_2000.wav、audio_am_noise.wav
第 18 帧 视频数据
12 帧 48×48 序列（抽帧 PNG 在 data/video_frames/）、帧间差分运动检测与逐帧亮度信号。		 06_datatype_video.py video_frames.npy
第 19 帧 图 / 网络数据
60 节点 BA 无标度网络的力导向布局（节点大小与颜色表示度数）与度分布双对数图。		 07_datatype_graph.py graph_edges.csv、graph_nodes.csv
第 20 帧 时空轨迹数据
深圳南山周边 3 条轨迹 × 120 个点：经纬度路径、hexbin 空间密度与速度时间序列。		 08_datatype_spatiotemporal.py spatiotemporal_tracks.csv
第 23 帧 截面 / 时序 / 面板
截面排序条形图、含 12 期移动平均的 120 个月 CPI、8 家公司 × 10 年的面板小多图。		 09_datastructure_cross_time_panel.py structure_cross_section.csv、structure_time_series.csv、structure_panel.csv

运行方式：pip install -r code/requirements.txt → cd code && python run_all.py； 样本写入 data/，图片写入 figures/。随机种子固定 20260917，每次运行结果完全一致。

Lecture 3 · 数据整备样本（10 个程序，逐行中文注释）

运行方式：pip install -r code/lecture03/requirements.txt → cd code/lecture03 && python run_all.py； 样本写入 data/lecture03/，图片写入 figures/lecture03/。随机种子固定 20260317，每次运行结果完全一致。

课件页整备主题程序（逐行中文注释）样本数据
第 15 帧 质量画像仪表盘 Quality profile
600 行脏订单：18 个重复主键、城市 7 种写法、支付状态 6 种写法、70 行缺数量，一次量化五项质量特征。		 l3_01_quality_profile.py l3_orders_dirty.csv、l3_quality_scorecard.csv
第 22 帧 连接语义对照 Join types
inner 5 · left 6 · right 8 · outer 9 · union 10 行：五种操作的结果表与行数变化；含 validate 报错演示。		 l3_03_join_types_validate.py l3_customers.csv、l3_orders.csv、l3_dataset1.csv、l3_dataset2.csv、l3_dataset3.csv、l3_dataset4.csv
第 26 帧 concat 与 schema 对齐
两期订单抽取：朴素拼接 9 列（全空洞）→ 对齐后 7 列干净；行数与主键两条断言。		 l3_02_join_concat.py l3_orders_2026Q1.csv、l3_orders_2026Q2.csv、l3_orders_combined.csv、l3_concat_accounting.csv
第 29 帧 透视、交叉表与分箱
crosstab 频数、pivot_table 聚合、cut 等宽分箱与 qcut 等频分箱（6/6/6/6）。		 l3_04_reshape_toolbox.py l3_sales_wide.csv、l3_sales_long.csv、l3_sales_pivot.csv、l3_sales_long_enriched.csv
第 30 帧 宽表 / 长表 / 透视对照
4 门店 × 6 个月的三种摆法，含宽→长→宽往返无损断言。		 l3_04_reshape_toolbox.py l3_sales_wide.csv
第 38 帧 异常值三法
IQR 22 行 / Z 10 行 / 稳健 Z 17 行 / 隔离森林 13 行；四法一致仅 10 行；三种处置对比。		 l3_06_outliers_iqr_z_iforest.py l3_income_outliers.csv、l3_outlier_treatment.csv
第 41 帧 清洗前后对照
600 → 582 行；缺失 70 → 0（中位数填充 + 缺失指示列）；异常值标记而非静默删除。		 l3_05_cleaning_pipeline.py l3_orders_clean.csv、l3_cleaning_log.csv
第 46 帧 结构错误与类别规范化
城市 7 种写法 → 2 个城市；别名映射表本身也是交付物。		 l3_05_cleaning_pipeline.py l3_city_names_raw.csv、l3_city_names_map.csv
第 52 帧 缺失矩阵与机制偏差
MCAR / MAR / MNAR 三种机制的缺失矩阵与朴素均值偏差 −0.9% / −14.4% / −5.6%。		 l3_07_missing_mechanisms.py l3_missing_bias.csv、l3_income_missing_MCAR.csv、l3_income_missing_MAR.csv、l3_income_missing_MNAR.csv、l3_missing_panel_sample.csv、l3_missing_panel_coverage.csv
第 57 帧 插补前后：分布与关系
均值插补把分布压成尖峰；回归 / KNN / MICE 更接近真分布；方差收缩清晰可见。		 l3_08_imputation_compare.py l3_income_complete.csv、l3_income_missing.csv、l3_imputation_metrics.csv、l3_imputation_means.csv
第 62 帧 平衡面板 T=11, n=2
两家公司 11 个月的营收路径与个体 × 时间热力图（每格都有观测）。		 l3_09_panel_balance.py l3_panel_balanced.csv
第 68 帧 面板补齐前后热力图
T1=9 / T2=11 / T3=8 与块状缺失 → 按个体插值（2 格）并标注；5 格因期间不存在而无法补齐。		 l3_09_panel_balance.py l3_panel_unbalanced.csv、l3_panel_repaired.csv
第 72 帧 变换与标准化效果
偏度 ≈ 2.7 的营收经 log1p 后接近对称；12 条 schema 断言全部通过。		 l3_10_transform_assert.py l3_income_skewed.csv、l3_transform_summary.csv、l3_schema_report.csv

Lecture 4 · 数据描述与可视化样本（13 个程序，逐行中文注释）

运行方式：pip install -r code/lecture04/requirements.txt → cd code/lecture04 && python run_all.py； 样本写入 data/lecture04/，图片写入 figures/lecture04/，交互 HTML 写入 figures/lecture04/interactive/。 随机种子固定 20260417，每次运行结果完全一致；全部用 Python 完成（不使用 Power BI / Tableau）。

课件页可视化主题程序（逐行中文注释）样本数据 / 交互产物
第 13 帧 文档完成度与数据字典 Document coverage
500 行调研样本：20 项文档要素逐项打分（20/20 已填）、字段非空率与自动生成的数据字典（9 个字段）。		 l4_01_docs_metadata.py l4_survey_raw.csv、l4_data_dictionary.csv、l4_data_dictionary.md、l4_docs_coverage.csv
第 23 帧 中心趋势的稳健性 Robust centre
1000 个收入观测加 3 个离群点：均值移动 +12.5%、中位数只移动 +0.7%；均值/中位数/标准差/IQR/MAD 对照。		 l4_02_descriptive_stats.py l4_income_skewed.csv、l4_descriptive_table.csv
第 24 帧 离散与分布形状 Dispersion & shape
同均值不同离散、三个离散指标对照、偏度（左偏/对称/右偏）、峰度（厚尾 t(3)/正态/薄尾均匀）。		 l4_02_descriptive_stats.py l4_descriptive_table.csv
第 28 帧 同一变量五种画法 Five univariate charts
城市 GDP 的直方图、箱线图、小提琴图、ECDF 与茎叶图：换图型就换视角，分箱决定观感。		 l4_05_chart_zoo.py l4_city_gdp.csv
第 37 帧 受限范围与相关系数 Restricted range
引力模型 220 对国家对：全样本 Pearson −0.589 / Spearman −0.606，只留最近 25% 的伙伴后降到 −0.200 / −0.213。		 l4_03_correlation_crosstab.py l4_trade_pairs.csv、l4_correlation_pearson.csv、l4_correlation_spearman.csv
第 38 帧 多变量三视图 Multivariate views
60 家企业 × 8 年面板：相关矩阵热力图、按行业着色的散点、行业营收小多图、各行业 ROA 条件分布。		 l4_04_multivariate.py l4_firm_panel.csv、l4_conditional_roa.csv
第 52 帧 七类图型总览 Chart zoo
柱状图、分布图、趋势图、散点图、相关矩阵、条形图、网络图，外加一格"按问题选图"的口诀。		 l4_05_chart_zoo.py l4_city_gdp.csv、l4_category_counts.csv
第 64 帧 交互图与静态图 Interactive vs static
132 个月 × 4 类能源：静态图用于定稿汇报，交互 HTML（折线/散点/桑基）用于探索与课堂演示。		 l4_06_plotly_interactive.py l4_energy.csv　能耗趋势（交互） ↗　收入散点（交互） ↗　桑基图（交互） ↗
第 66 帧 Python 仪表板 Dashboard
KPI 卡（样本量、满意度、复购率、人均 GDP 中位数）+ 2×2 面板；plotly 子图导出单文件 HTML，替代 BI 工具。		 l4_07_dashboard.py l4_dashboard_kpi.csv　仪表板（交互） ↗
第 70 帧 choropleth 与符号地图 Geo maps
31 个省级单位与 24 个经济体：GeoJSON 分级统计图、总量气泡图、世界 choropleth 与贸易流向图。		 l4_08_geo_maps.py l4_province_gdp.csv、l4_country_indicators.csv、china_provinces.geojson　世界 choropleth（交互） ↗　贸易流向图（交互） ↗
第 72 帧 空间自相关 Moran 散点
4 近邻权重矩阵：Moran's I = 0.659，HH 16 / LL 13 / LH 2——人均 GDP 存在明显的正向空间聚集。		 l4_08_geo_maps.py l4_moran.csv
第 79 帧 六种误导手法与修正
截断纵轴、气泡按半径、双轴伪相关、选择性区间、饼图讲相近占比、丢掉不确定性：上排误导、下排修正。		 l4_09_misleading.py l4_ab_test.csv
第 83 帧 不确定性四视图 Uncertainty
B=2000 次自助重采样：误差棒、差值分布与区间（[−0.0056, +0.0456] 跨 0）、时间序列置信带、扇形预测带。		 l4_10_uncertainty.py l4_ab_test.csv、l4_uncertainty_summary.csv
第 85 帧 色板与灰度可访问性 Palette accessibility
三套色板的原色/灰度对照、感知亮度分布与 WCAG 对比度矩阵（≥4.5 达标），附 12 项可访问性清单。		 l4_11_accessibility.py l4_category_counts.csv、l4_accessibility_report.csv、l4_accessibility_checklist.csv
第 89 帧 三种降维投影对照 Projections
同一份 12 维客户数据：PCA（前两成分 21.8% + 10.5%）、t-SNE、UMAP 三种投影，附碎石图与邻域保真度（t-SNE 0.89 / UMAP 0.85 / PCA 0.75）。		 l4_13_highdim.py l4_highdim_customers.csv、l4_highdim_projection_metrics.csv　三维嵌入（交互） ↗
第 93 帧 多变量剖面 Parallel & clustered
8 个标准化特征的平行坐标（三个群体均值剖面）、按层次聚类重排的相关热力图、以及只作示意的雷达图。		 l4_13_highdim.py l4_highdim_customers.csv
第 94 帧 模型解释性可视化 Interpretability
随机森林预测流失：置换重要性（最近购买距今天数 0.195，10 次重复带误差棒）、PDP 平均边际效应与 60 条 ICE 个体曲线。		 l4_13_highdim.py l4_highdim_importance.csv
第 98 帧 报告主图与图注 Report pipeline
统计表 + 四联报告图 + 自足图注一次导出：纵轴截断、缺失处理、误差棒与样本量都写在图注里。		 l4_12_report_pipeline.py report/table1_descriptive.csv、report/table2_channel.csv、report/captions.md

如何运行 How to Run

# 1) 安装依赖（Python 3.8+；本课程用 3.9 实测）
pip install -r code/requirements.txt
pip install -r code/lecture03/requirements.txt
pip install -r code/lecture04/requirements.txt

# 2) Lecture 2：数据类型样本（逐行中文注释）
cd code
python run_all.py

# 3) Lecture 3：数据整备样本（逐行中文注释）
cd lecture03
python run_all.py

# 4) Lecture 4：描述统计与可视化样本（逐行中文注释）
cd ../lecture04
python run_all.py

三个讲次的随机种子都固定（L2 为 20260917、L3 为 20260317、L4 为 20260417）， 因此每次运行得到完全相同的样本与图片。Lecture 4 的省级边界文件在首次运行时自动下载并缓存到 data/lecture04/china_provinces.geojson；若网络不可用，地图自动退化为中心点气泡图，流程不会中断。

说明 Notes

  • 逐行注释：Lecture 2、Lecture 3 与 Lecture 4 的程序、以及课件中的代码示例，每一行代码都带中文注释；
  • 数据来源：全部样本由程序合成（模拟订单、客户、收入、城市面板、语料、网络等），不包含任何真实个人数据，可自由用于教学与项目 1；
  • 与课件对应：L2 图片对应第 10、12、13、15–20、23 帧；L3 图片对应第 15、22、29、30、38、41、46、52、57、62、68、72 帧；
  • 拓展建议：把 l3_01_quality_profile.py 的数据源换成你自己的表，即可直接得到项目 1 所需的数据质量报告。

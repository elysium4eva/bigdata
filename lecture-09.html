本讲是从第一性原理到工程的一条线： 视觉简史（暗箱→Marr→SIFT→Viola-Jones→ImageNet 22K/14M）→ 图像分类的五大挑战与 k-NN 基线（为什么它在图像上从不用）→ 参数化方法与线性分类器（softmax + 交叉熵 + 梯度检验）→ 多层网络与反向传播（链式法则、计算图、autograd、优化器、正则化）→ CNN（卷积三个先验、感受野、残差、迁移学习）→ 序列与 Transformer（RNN 瓶颈、注意力、自注意力、BERT vs GPT）→ 预训练-微调（线性探测 / 全量微调 / LoRA 2,178 参数拿到 1.000）→ 训练工程（批大小、梯度累积、显存账）→ 2026（量化端侧、对齐与成本）。

2026-10-22 现场案例（帧 48–49）：用仓库 dxawdc/stock-heatmap 抓取当天全市场快照（腾讯行情 + 申万一级行业成分），再静态渲染成树图： 5,568 只股票中取成交额前 697 只、按 31 个申万一级行业分组，面积=成交额、颜色=涨跌幅。 当日上证 A 股指数 −1.48%，个股中位数 −3.54%，31 个行业 6 涨 25 跌 （家电 +1.1%、石油石化 +0.5%；环保 −7.1%、通信 −6.8%）。 可打开 交互版热力图（页面内切换分组、Top-N 与筛选）。 这张图正是帧 43「通道有效性」与帧 44「按问题选图」在真实数据上的一次落地： 位置分组、面积表量级、颜色表方向，三个通道叠在一张图里。

一、历史与版图 Landscape
深度学习deep learning多层可微网络的表示学习

目标检测object detection定位并分类多个物体
语义分割semantic segmentation给每个像素一个类别
二、从 kNN 到线性分类器 Classification
数据驱动data-driven approach用数据学函数，而非手写规则
最近邻nearest neighbour取距离最近的训练样本的标签
k 近邻k-nearest neighbours (k-NN)取最近 k 个投票或平均
距离度量distance metricL1/L2/余弦；决定什么算相近
维度灾难curse of dimensionality$\mathrm{nn}/\mathrm{fn}\to1$高维下距离失去区分度
超参数hyper-parameter训练前设定，例如 k、学习率
验证集validation set选超参数用，不能是测试集
参数化方法parametric approach用参数概括数据，不存全部样本
线性分类器linear classifier$s=Wx+b$用线性打分做分类
得分函数score function$s=Wx$把输入映射到各类得分
softmaxsoftmax$e^{z_k}/\sum_j e^{z_j}$把得分变成概率
交叉熵cross-entropy$-\sum_k y_k\log p_k$分类的负对数似然
温度temperature$T$softmax 的锐度旋钮
三、神经网络与反向传播 Networks
激活函数activation function$h=\phi(Wx+b)$引入非线性
sigmoidsigmoid$1/(1+e^{-z})$压到 (0,1)，易饱和
ReLUrectified linear unit (ReLU)$\max(0,z)$不饱和、计算便宜
GELUGaussian error linear unit (GELU)Transformer 常用激活
反向传播backpropagation$\partial L/\partial w$用链式法则从输出往输入求梯度
链式法则chain rule复合函数的求导规则
计算图computational graph把运算记成图，便于自动求导
自动微分automatic differentiation由计算图自动算梯度（autograd）
梯度消失vanishing gradient深层网络梯度趋近 0
梯度爆炸exploding gradient梯度爆炸导致发散
学习率learning rate$\eta$步长；过大发散、过小慢
动量momentum$v_t=\beta v_{t-1}+g_t$累积惯性抑制震荡
AdamAdam自适应步长 + 偏差校正
权重衰减weight decay$\lambda$L2 正则的等价写法
dropoutdropout训练时随机丢弃神经元
早停early stopping验证损失不再下降就停
批归一化batch normalisation按批标准化激活，稳定训练
初始化initialisationXavier/He 控制初始方差
四、卷积神经网络 CNN
卷积convolution$(f*g)(t)$局部加权求和，参数共享
卷积核kernel / filter可学习的小模板
步长stride滑动步幅
填充padding边界补零以保持尺寸
通道channel特征图的深度
感受野receptive field一个输出能看到的输入范围
池化pooling下采样，扩大感受野
残差连接residual connection$y=x+F(x)$恒等捷径，缓解深层退化
迁移学习transfer learning用预训练权重做新任务
数据增强data augmentation翻转/裁剪/扰动，免费的正则
生成对抗网络generative adversarial network (GAN)生成器与判别器对抗
扩散模型diffusion model学去噪过程来生成样本
五、序列与 Transformer Sequences
循环神经网络recurrent neural network (RNN)按时间步递归处理序列
长短期记忆long short-term memory (LSTM)门控结构，缓解梯度消失
序列到序列sequence to sequence (seq2seq)编码器-解码器结构
注意力attention$\alpha=\mathrm{softmax}(q^\top k)$按相关性加权求和
自注意力self-attention$\mathrm{softmax}(QK^\top/\sqrt{d})V$序列内部互相看
多头注意力multi-head attention多组投影并行，学不同关系
位置编码positional encoding给序列注入顺序信息
TransformerTransformer纯注意力架构，可并行
编码器-解码器encoder-decoder编码输入、解码输出
掩码语言模型masked language model预测被遮住的词（BERT）
自回归autoregressive按前面预测下一个（GPT）

预训练pretraining在大规模无标注数据上训练表示
微调fine-tuning在预训练模型上继续训练

提示学习prompting用提示词调用模型，不改参数

图神经网络graph neural network (GNN)在图上做消息传递

对齐alignment让模型行为符合人类意图与规范

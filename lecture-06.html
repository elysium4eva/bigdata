本讲是推导课：最小二乘与正规方程（含投影几何）、极大似然与损失函数的来源 （l₂ ＝ 高斯 ＋ MLE）、线性分类与 sigmoid 的三条性质、逻辑回归 ＝ sigmoid ＋ 交叉熵、 交叉熵损失梯度的推导、手写梯度下降与 PyTorch 自动求导对账、softmax 多分类、类别不平衡与代价敏感阈值、 概率校准（等渗回归 / Platt）、LASSO / Ridge / Elastic Net 与交叉验证、偏差-方差分解， 以及一张 79 条术语表。全部示例用 Python 完成，每一行代码都带英文注释。

本讲结构 Outline

Part 0封面与导航：学习目标、路线图、与 L5 衔接、本讲输出物（四条推导 + 手写梯度下降对账 + 术语表）、全讲导览
Part 1从任务到数学形式：三类任务与核心术语、图像分类与多分类、聚类、颜色直方图到特征向量、形式化六步（假设类 → 同分布 → i.i.d. → 期望损失 → 0-1/l₂ 损失 → 经验损失）、泛化差距、机器学习 1-2-3、表征学习、1-2-3 的边界与非 i.i.d.
Part 2线性回归与正规方程：前列腺数据、假设类与 MSE、矩阵形式、正规方程推导、投影几何样本页、增广技巧、三种实现代码页、为什么是 l₂、共线性与条件数、数值稳定样本页与代码页（lstsq / QR / 伪逆）、评估与外推
Part 3极大似然与损失函数：分布族与参数、似然与联合似然、对数似然、负对数似然、条件似然（判别式 vs 生成式）、l₂ ＝ 高斯 ＋ MLE 推导、伯努利似然样本页、交叉熵与 KL 散度、一维 NLL 曲面样本页、MLE 代码页、下溢与 log-sum-exp 样本/代码页
Part 4线性分类与逻辑回归：超平面与间隔、step ＋ 0-1 损失的三重困难（NP-hard）、回归当分类的缺陷、离群点样本页、三条曲线样本页、sigmoid 三性质与推导、sigmoid 样本页、逻辑回归＝sigmoid＋MLE、对数几率与几率比、无闭式解、梯度推导、手写梯度下降代码页、收敛与学习率样本页、PyTorch 自动求导代码页、优化器与早停、标准化、softmax 与代码页、softmax 区域样本页、类别不平衡样本页、阈值与代价、校准与 ROC/PR 样本页
Part 5正则化与监督学习结构：为什么正则化、惩罚回归、LASSO / Ridge / Elastic Net、正则化路径样本页、交叉验证代码页、1-SE 规则、偏差-方差分解、近似-过拟合样本页、预测问题统一框架、计量经济学 vs 机器学习术语对照、平方误差案例、混淆矩阵与 ROC 代码页、监督学习者三要素、线性模型家族
Part 6工具、术语与结语：工具栈分工、statsmodels 推断代码页（系数/标准误/p 值/区间/几率比）、术语表三帧（79 条）、常见错误 Top 10、与 L7/L9/L12 的衔接、三句话讲清一个线性模型

代码示例（10 页，逐行英文注释）Code Walkthroughs

中文English符号 / 公式说明
一、基本概念 Concepts
机器学习machine learning从数据中学习函数以完成预测或决策
监督学习supervised learning训练数据带标签 (x_i, y_i)
无监督学习unsupervised learning训练数据无标签，发现结构
二分类binary classification输出两个类别，如欺诈/正常
多分类multi-class classification输出三个及以上类别
训练数据training data用于学习函数的数据
测试数据test data用于评估的未见数据
特征向量feature vector$x_i$一个样本的输入表示
标签label$y_i$样本的目标值
假设类hypothesis class$\mathcal{H}$候选函数的集合，决定模型族
独立同分布independent and identically distributed (i.i.d.)训练与测试同分布且相互独立
期望损失expected loss / risk$L(f)$ $E_{x,y\sim D}[l(f,x,y)]$对数据分布的期望误差
经验损失empirical loss / empirical risk$\hat L(f)$ $\frac1n\sum_i l(f,x_i,y_i)$样本平均误差
0-1 损失0-1 loss$\mathbb{I}[f(x)\ne y]$误分类即 1，否则 0
平方损失squared loss / $l_2$ loss$(f(x)-y)^2$回归的默认损失
泛化差距generalization gap期望损失与经验损失之差
过拟合overfitting拟合训练噪声，样本外变差
表征学习representation learning自动学习特征表示
二、线性回归 Linear Regression
线性回归linear regression$f_w(x)=w^\top x$线性假设类 + 平方损失
均方误差mean squared error (MSE)$\frac1n\sum_i(w^\top x_i-y_i)^2$平方损失的平均
正规方程normal equation$w=(X^\top X)^{-1}X^\top y$梯度为零得到的闭式解
设计矩阵design matrix$X$第 i 行为 $x_i^ op$ 的矩阵
截距intercept / bias$b$常数项，可用增广列实现
增广技巧augmented trick$x'=(x,1)$把截距并入权重向量
投影projection最小二乘解是 y 在列空间的投影
条件数condition number$\kappa$输入微小扰动引起的解的相对变化
多重共线性multicollinearity特征高度线性相关，$X^ op X$ 病态
三、极大似然与损失 Likelihood and Loss
极大似然估计maximum likelihood estimation (MLE)$\hat\theta_{ML}$ $\arg\max_\theta\prod_i P_\theta(x_i,y_i)$选让数据最可能的参数
似然likelihood$P_\theta(x_i,y_i)$参数对数据的拟合程度
对数似然log-likelihood$\sum_i\log P_\theta(x_i,y_i)$把乘积变求和，数值更稳
负对数似然negative log-likelihood (NLL)$-\sum_i\log P_\theta(x_i,y_i)$常用作损失函数
条件似然conditional likelihood$P_\theta(y\mid x)$判别式建模，只关心 y 给定 x
判别式模型discriminative model$P(y\mid x)$直接建模条件分布
生成式模型generative model$P(x,y)$建模联合分布
交叉熵cross-entropy$-\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)]$分类的 NLL 形式
KL 散度Kullback-Leibler divergence$D_{KL}(p\Vert q)$两个分布的差异，交叉熵减熵
下溢underflow概率连乘趋近于 0，需取对数
对数求和指数log-sum-exp$\log\sum_k e^{z_k}$稳定计算对数概率和的技巧
四、线性分类与逻辑回归 Classification
线性分类器linear classifier$w^\top x=0$用超平面划分两类
超平面hyperplane$w^\top x+b=0$线性决策边界
间隔margin样本到决策边界的距离
阶跃函数step function$\mathrm{step}(z)=\mathbb{I}[z>0]$硬分类器，不可导
sigmoid 函数sigmoid function$\sigma(z)$ $1/(1+e^{-z})$把实数压到 (0,1)
逻辑回归logistic regression$P(y=1\mid x)=\sigma(w^\top x)$sigmoid + 交叉熵（MLE）
对数几率log-odds$\log\frac{p}{1-p}=w^\top x$系数解释为对数几率的变化
几率比odds ratio$e^{w_j}$特征增加一单位对几率的倍数
梯度下降gradient descent$w\leftarrow w-\eta\nabla L$沿负梯度迭代下降
学习率learning rate$\eta$步长，过大发散、过小慢
批量batch一次更新使用的样本数
自动微分automatic differentiation由计算图自动求梯度（如 PyTorch）
凸函数convex function局部最优即全局最优
softmaxsoftmax$e^{z_k}/\sum_j e^{z_j}$多分类的概率输出
类别不平衡class imbalance正类稀少，准确率会误导
阈值threshold概率转硬标签的临界值
第一类错误Type I error (false positive)误报：把负例判为正
第二类错误Type II error (false negative)漏判：把正例判为负
混淆矩阵confusion matrixTP/FP/FN/TN 四格表
ROC 曲线ROC curve不同阈值下的 TPR 与 FPR
AUCarea under the ROC curve排序能力的单一指标
精确率precision$TP/(TP+FP)$预测为正中有多少真的正
召回率recall / sensitivity$TP/(TP+FN)$真的正中有多少被找到
概率校准probability calibration预测概率与实际频率一致
等渗回归isotonic regression单调校准方法
Platt 缩放Platt scaling用逻辑回归做校准
布里尔分数Brier score$\frac1n\sum(p_i-y_i)^2$概率预测的均方误差
五、正则化与推断 Regularisation and Inference
正则化regularization用惩罚项控制模型复杂度
惩罚回归penalized regression$\text{RSS}+\lambda\,\Omega(w)$损失加惩罚项
L1 惩罚L1 penalty / LASSO$\lambda\sum_j|w_j|$产生稀疏解，自动选择特征
L2 惩罚L2 penalty / Ridge$\lambda\sum_j w_j^2$向零收缩但不为零
弹性网elastic net$\lambda(\alpha\sum|w_j|+(1-\alpha)\sum w_j^2)$L1 与 L2 的混合
超参数hyper-parameter$\lambda$学习前需设定的参数
稀疏解sparse solution多数系数恰为零
收缩shrinkage系数向零靠拢
偏差-方差分解bias-variance decomposition$E[(y-\hat f)^2]=\text{Bias}^2+\text{Var}+\sigma^2$期望误差的三个来源
近似误差approximation error函数类表达能力的限制
交叉验证cross-validation轮流留出验证折评估模型
标准误standard error$\hat\sigma/\sqrt n$估计量的抽样波动
置信区间confidence interval参数的区间估计
p 值p-value在原假设下观测到该统计量的概率
